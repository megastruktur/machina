First-run failures (preserved, no retry-until-green; root causes fixed in
the slice/tests, not in the evidence):

1. `RuntimeError: asyncio.run() cannot be called from a running event
   loop` — the sync `_run` helper was used inside async tests; the
   write+index helper became `async` and every async call site awaits.
2. `ValueError: badly formed hexadecimal UUID string` — fixture UUID
   `DOC_B_ONLY` had a 10-char final group; fixed to a canonical 36-char
   form.
3. `psycopg.errors.AmbiguousParameter: could not determine data type of
   parameter $3` on `($3 IS NULL OR d.namespace = $3)` with a NULL bind —
   the storage scope predicate now casts: `(CAST(:namespace AS text) IS
   NULL OR d.namespace = CAST(:namespace AS text))`.
4. Hybrid-ranking test asserted strict order between the dual-signal doc
   and the pure-FTS doc; with equidistant unit-basis filler vectors a
   (1,2)-vs-(2,1) RRF tie is possible by construction, so the test now
   pins channel attribution (rank-null patterns) and the strict
   inequalities that are mathematically robust, with a comment why.
5. `KeyError: 'error_code'` against the real bridge ToolResult — the
   frozen JSON nests the code under `error.code`; assertion corrected.

## Limitations

- Query-embedding and index-embedding round trips run against the pinned
  `openai` SDK surface with deterministic local fixtures (offline
  discipline per test policy); a live gateway round trip is the feature
  gate's (`07-verify`) assembled-journey concern, same as 07-chunk-index.
- The vector channel is k-NN by design: a non-matching query over a
  non-empty scope returns that scope's closest chunks (rank conveys
  weakness via score/ranks); zero results is the empty-scope state. No
  arbitrary relevance threshold was invented.
