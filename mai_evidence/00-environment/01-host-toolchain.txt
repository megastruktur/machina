ANOMALY: ~/.local/bin is an rtk shim layer. The `pytest` shim target is missing, so global pytest
is broken even though `command -v pytest` resolves. `jq` resolves to `jaq 2.3.0` through the same
layer. Consequence recorded in the ADR: Python tooling must run inside uv-managed project venvs
(`uv run pytest`), not through global shims. (No dependencies were installed for this probe.)
